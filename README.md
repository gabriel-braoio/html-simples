# HTML Simples

Conjunto de exercícios introdutórios de **HTML5**, feitos durante os estudos de
desenvolvimento web. Cada arquivo explora um recurso básico da linguagem: links,
tabelas e imagens.

---

## Exercícios

| Arquivo | Conteúdo |
|---|---|
| `exercicio1entrega.html` | Página inicial com lista de dicas de estudo e links para os demais exercícios |
| `exercicio2entrega.html` | Tabela com remédios e informações de tratamento |
| `exercicio3entrega.html` | Exibição de imagens (`<img>`) com largura e altura definidas |

## Como Visualizar

Basta abrir os arquivos `.html` diretamente no navegador, começando por
`exercicio1entrega.html`, que serve de índice para os outros exercícios.
